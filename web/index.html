    Know what is running

    A small lab.
    Clear boundaries.

    Real orchestration and adaptation mechanics, with an honest separation
    between deterministic teaching fixtures and model-backed review.

    1

    LangGraph owns execution

    The local application uses a real StateGraph and SQLite checkpointer. The graph pauses at an interrupt, survives process restart, and resumes after an explicit human decision.

    2

    Harness² owns experiments

    A custom document adapter connects the pinned upstream recursion and reflection core to real LangGraph runs. Scripted edits switch between two allowlisted review profiles.

    3

    Evidence is enforced

    Every finding must quote its exact source line. Unsupported and duplicate findings are withheld. A valid quote demonstrates grounding, not that the interpretation is correct.

    4

    Human approval is separate

    Document content cannot approve itself. Publication writes one local report; repeated decisions are rejected and the report has a unique run identifier.

    Run the full application

    uv sync --locked
uv run tracework serve

    For a real model, optionally select the local Ollama reviewer. The default offline mode remains deterministic and transparent.
